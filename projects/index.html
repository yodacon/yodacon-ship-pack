Sample projects

Small, finished projects to copy and build on. Plain HTML, CSS and JavaScript, no build step. Each folder has a README that explains how it works and how to move it into your own project.

  • DOM + Canvas game

    Konquest

    KDE's galactic conquest with its exact rules and computer players; the fleets fly as pack ships. Hot seat, or watch the computers.

    Source and README

  • Canvas + DOM game

    ConEx Courier

    Escape Velocity in miniature: four systems, trade, courier missions, pirates and a shipyard of the ten 1997 hulls. Work up to a Large Pin.

    Source and README

  • Canvas game · Gamepad API

    Gauntlet

    Pick any of the thirteen designs and fight the others one by one, ending with the 1998 Yodacon. One or two players, keyboard or gamepads.

    Source and README

  • Canvas game

    Rally

    Three laps through gates around planets against five computer racers; every hull handles by its 1997 record. Three tracks, best times kept.

    Source and README

  • Canvas + DOM game

    Convoy

    Escort a Large Pin freighter through pirate raids with two wingmen who take your orders. Targeting pictures and comm portraits, as in EV.

    Source and README

  • Canvas game

    Picket

    Tower defence: build six hulls beside the lane and hold the station against fifteen waves of raiders. Prices, range and guns from the 1997 records.

    Source and README

  • Pure DOM memory game

    Recall

    Match each ship across two of its pictures: sprite and shipyard picture, shipyard and targeting picture, or comm portrait and targeting picture.

    Source and README

  • Canvas game

    Blockade

    A vertical scroller: bank through the frames, run two stages of raiders, and take down the Large Pin and the 1998 Yodacon.

    Source and README

  • Canvas game

    Dock

    Bring ten hulls home to a turning Large Pin with a main engine, a retro and inertia. Match the carrier's sprite frame and the tractor beam takes you in.

    Source and README

  • Canvas game

    Crossing

    Frogger with the pack: hop through traffic, ride the freighters across the ion stream, fill five bays. Everything flies on frames 9 and 27.

    Source and README

  • Canvas game

    Salvo

    Battleship by the salvo rule: one shot per ship afloat, ConEx against Override and konex pirates, a probability-map opponent, targeting pictures for the sunk.

    Source and README

  • Canvas game

    Flak

    Missile Command: raiders dive on the fleet on the frame for their line of attack; Defender batteries turn to aim; Necromancers split, kills chain.

    Source and README

  • Canvas game

    Formation

    Snake: rescued ships fall in behind the Yodacon, each on the frame for its own heading, every hull drawn at one length.

    Source and README

  • Canvas puzzle

    Refit

    Match-3: ships turn on their frames to face the way they move; Yodacon bombs and Large Pin line-clearers.

    Source and README

  • DOM card game

    Fleet Tactics

    Draft a fleet within a budget, then fight card by card. Hull, firepower and initiative from each ship's 1997 record.

    Source and README

  • Canvas game

    Orbital Defence

    Hold a planet against waves of ConEx ships: aim its cannon, buy Advisor patrols, repair between waves.

    Source and README

  • Canvas game

    Slingshot

    Gravity golf with the 1997 Dart: pull back, let go, and let the planets bend it through the gate. Six levels against par.

    Source and README

  • Pure DOM idle game

    Pin Miner

    Pins mine an asteroid field and haul the ore home; buy more ships and upgrades. Earns at half rate while you're away.

    Source and README

  • DOM quiz

    Cutaway

    Name the ship from its 1997 targeting cutaway, against the clock: scanning and mirrored rounds, streak bonuses.

    Source and README

  • Pure DOM

    Shipyard

    Every ship, its pictures, stats and 1997/98 description; a sprite you drag to turn; buy a fleet with credits.

    Source and README

  • Pure DOM game

    DOM Dogfight

    Waves of missile-firing Defenders. Every object is a <div>; fixed-timestep loop, touch controls.

    Source and README

  • three.js

    Fleet Flyby

    Every ship in formation along a spline, as billboards that turn as you orbit. Click one for its pictures.

    Source and README

  • three.js

    Hangar

    One ship on a turntable whose frame follows the table; its shipyard, target and comm pictures on monitors.

    Source and README
