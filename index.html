The ships

Every ship is a 36-frame sprite — frame 00 nose-up, 10° clockwise per frame — plus the plugin's target, shipyard, comm and thumbnail pictures. Two editions: the original for Escape Velocity, and the larger, re-rendered fleet for EV Override.

Use it in your project

No build step, no npm. Pick a way to reach the files; the library finds the rest relative to itself.

1 · Vendor the folder

Clone or copy the whole pack (with LICENSE) into your site, and use relative paths.

<script type="module" src="vendor/yodacon-ship-pack/lib/yodacon-ship-pack.js"></script>

2 · jsDelivr, pinned

A release tag never changes; CORS headers included, so WebGL works.

<script type="module" src="https://cdn.jsdelivr.net/gh/yodacon/yodacon-ship-pack@v1.0.0/lib/yodacon-ship-pack.js"></script>

3 · Link to yodacon.org

The newest release, served from the project's own site.

<script type="module" src="https://yodacon.org/ship-pack/lib/yodacon-ship-pack.js"></script>

A sprite in HTML: <yodacon-ship>

<yodacon-ship ship="yodacon" spin></yodacon-ship>
<yodacon-ship ship="dart" edition="override" heading="90" scale="1"></yodacon-ship>

Attributes: ship, edition (conex | override), heading, scale, spin, base. All live.

Canvas 2D: drawShip()

import { loadShip, drawShip } from "https://cdn.jsdelivr.net/gh/yodacon/yodacon-ship-pack@v1.0.0/lib/yodacon-ship-pack.js";

const ship = await loadShip("conex", "yodacon");
drawShip(ctx, ship, headingDeg, x, y, 2);   // centred, pixelated

Where they came from

  1. 1997ConEx 1.2 — Paul Richeson's plugin for Ambrosia Software's Escape Velocity: ten ships for the government of Consolidated Express.
  2. 1998ConEx Override 1.0 — the fleet rebuilt for EV Override: larger sprites, and a new hull, the Callisto.
  3. 2005konex — Joshua Bussdieker's C++/OpenGL remake, which took Override's ten hulls as its cast and added Advisor and Citrus.
  4. 2026Gonex — a Go/Ebitengine port of konex that restores ConEx's own game.
  5. 2026This pack — built by Yodacon (yodacon.org).

How they were made

From the ConEx 1.2 readme — The stuff I used to make this plugin, in order from most important to least important:

Infini-D
to design the ships
EV-Edit
to make everything except missions
Schmelta-V
to make missions
ResEdit
to renumber resources and fix what EV-Edit broke
GraphicConverter
to convert all images to PICT and make the target graphics
Make spïn
to gather the 36 individual PICT files into sprites and masks
an Iomega Zip drive
to store all the files
the Escape Velocity Data file
for its TMPL resources, so ResEdit could edit
Escape Velocity
to test
DOCMaker
for the readme
Bryce 2
for the landing screens

The original readmes: ConEx 1.2 · ConEx Override 1.0.

In 2026 they were extracted with the pack's own pure-Python tools (tools/: BinHex, StuffIt 5 Arsenic and classic method 13, resource forks, QuickDraw PICT).
