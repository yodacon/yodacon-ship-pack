Examples

One small page for each way of drawing the ships. Each loads one ship (any ?edition=&ship= from the catalogue works) and lets you turn or fly it. Frameworks are pinned to exact versions on jsDelivr; nothing needs installing. Every folder has a README that walks through the code.

  • No library

    DOM + CSS

    background-position on sheet-alpha.png. No canvas.

  • No library

    Canvas 2D

    An 80-line game loop with the library's drawShip().

  • Web component

    <yodacon-ship>

    Every ship spinning, and the element's attributes.

  • three.js 0.160.0

    three.js

    A textured quad flown over a grid, and a billboard sprite you orbit.

  • Phaser 3.80.1

    Phaser

    load.spritesheet, Arcade physics, setFrame from heading.

  • PixiJS 8.6.6

    PixiJS

    36 textures over one source, ticker-driven flight.

Want more? The demo game is the full version, the sample projects are complete little apps, and the playground runs any of this in your browser.
